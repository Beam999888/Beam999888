## 🎮 Food For Life – เกมที่ช่วยให้คุณตระหนักเรื่องการเลือกกิน!

คุณจะต้องเก็บอาหารที่มีประโยชน์ให้ได้มากที่สุด เพื่อทำคะแนนและรักษาสุขภาพของตัวละคร  
แต่ระวัง! อาหารที่ไม่มีประโยชน์จะทำให้คะแนนของคุณลดลงทันที 🍔⬇️

เหมาะทั้งเด็ก ผู้ใหญ่ และคนที่อยากฝึกทักษะการตัดสินใจอย่างรวดเร็ว ⚡
